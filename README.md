# 24Plan
24Plan is a CLI application designed to help students reduce their decision-making times during study and work and actually focus on what matters.
## The reason behind it
I have always gotten distracted, overloaded by having to decide what to do, how to do and where to do. These simple questions soon became obstructions to my study schedule and often made me procrastinate a lot. \
This python CLI tool has helped me greatly reduce it as i now just have to pre-determine what exactly will be done and how will it be done the night before.
